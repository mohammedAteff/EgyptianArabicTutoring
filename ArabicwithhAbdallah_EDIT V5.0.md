**All-Writer Pre-Booking Publication Serialization:** Concurrently publishing two forms with the pre\_booking trigger serializes such that only one active form exists, atomically setting published\_version\_id from the locked active\_version\_id after asserting version validity and ownership.

**Form Author Immutability:** Editing a form or creating a new version preserves original forms.created\_by.

**Concurrent Draft Autosave:** Concurrent autosaves by the same student on the same form version serialize into exactly one draft row, strictly querying status = 'draft' and resolving the form version server-side.

**Cookie Authority \& Parameter Neutrality:** Authorization is governed exclusively by valid HTTP cookies. Submitting arbitrary, spoofed, or conflicting visitor\_token / session\_token strings in the request body or query parameters has zero effect on authorization. Missing authoritative cookies returns 403 Forbidden.

**Granular Challenge Hash Replay \& Race Verification:**

Ordinary replay: Submitting an already consumed challenge hash is intercepted by the locked pre-check and returns HTTP 409 Conflict.

Concurrent collision: Bypassing the pre-check under a simulated concurrent write race triggers HTTP 409 Conflict specifically from the database catch block on resource\_requests\_consumed\_challenge\_hash\_unique.

**Immediate Fifth PIN Attempt Invalidation:** Submitting five incorrect PIN attempts immediately purges the challenge from cache and returns 429 Too Many Requests on the fifth attempt.
